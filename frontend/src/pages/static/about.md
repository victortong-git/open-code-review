# About

This is an Open Source Source Code Reviewing Tool Powered by Nvidia AgentIQ Toolkit and OpenAI. It is developed by Victor Tong.

## Purpose

The Review UI provides a comprehensive interface for reviewing source code, identifying vulnerabilities, and managing findings across projects. It leverages AI-powered analysis to provide deeper insights into code quality and security issues.

## Key Features

- Project-based organization of code reviews
- Automated code scanning for vulnerabilities
- Detailed file analysis and visualization
- Finding management and reporting
- AI-enhanced code suggestions

## Technologies

Built using modern web technologies including:
- React 19
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Chart.js for visualization

The source code is available on GitHub.
